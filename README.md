# NEXORA — The Future of Digital Innovation

A responsive multi-page creative technology studio website built with React, Vite, JavaScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract `NEXORA-WEBSITE.zip`.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Notes

- This is a frontend portfolio concept. NEXORA, its team profiles, projects, statistics, and testimonials are fictional demonstration content.
- The contact form validates input in the browser and displays a demo confirmation. It does not send or store messages until a backend service is connected.
- The 3D-inspired hero orb is created with CSS 3D transforms and layered gradients, so no separate 3D engine is required.
- Project imagery is loaded from Unsplash URLs and therefore requires an internet connection.
- Replace demo content, contact details, images, and social links before presenting it as a real business.
